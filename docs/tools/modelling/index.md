# Modelling and texturing

The 3D and texturing suites that can produce the game's model, animation and texture formats.

- [Blender](blender.md): the free 3D suite, with the community Alamo tools; the maintained route.
- [3DS Max 6, 8 and 9](autodesk.md): the original exporters, for versions nobody runs any more.
- [Substance Suite](../texturing/substance_suite.md): texturing; payware.
