# Empire at War tools

Tools made for the game's own file formats.

- [Map Editor](map_editor.md): the official editor for galactic and tactical maps.
- [Particle Editor](particle_editor.md): the community editor for the game's particle effects.
- [ALO Viewer](alo_viewer.md): the community viewer for the game's models and animations.
