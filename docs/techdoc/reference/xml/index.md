# XML

The game's data lives in XML: units, factions, campaigns, story plots and much else. These pages
cover what the parser accepts and how the story system reads its events and rewards.

- [Tag overview](xml-tag-overview.md): the tags the game parses, by owning type, from the
  database map export the map editor shipped with, plus the ones added since.
- [Story events and rewards](xml-events-rewards.md): every `STORY_*` event type and
  `Reward_Type` with its parameters, what triggers it, and what was verified on the game.
