### `function Process_Reinforcements()`

Processes all reinforcements received. Do not call it manually. It is called by `Pump_Service()` (PGCommands), i.e. on every `PumpEvents()`, and issues the pending `Reinforce_Unit(...)` commands queued by `ReinforceList(...)`. A script that does not pump events never gets its `ReinforceList(...)` units.

### `function ReinforceList(type_list, entry_marker, player, allow_ai_usage, delete_after_scenario, ignore_reinforcement_rules, callback)`

Adds a list of reinforcements to a given player's reinforcement pool.
The function only queues the requests and returns at once; `Process_Reinforcements()` issues one `Reinforce_Unit(...)` per type on the following `PumpEvents()` calls and collects the arriving units.

???+ note "Params"

    * `table type_list`
    * `GameObject|Position|AITargetLocation entry_marker`: The position to spawn the reinforcements at.
    * `Player player`: The player to reinforce. Required; with `nil` the function shows a message box and returns.
    * `boolean allow_ai_usage`: Whether the AI may use the reinforcements. If `true`, `Prevent_AI_Usage(false)` is called on each arriving unit.
    * `boolean delete_after_scenario`: If `true`, `Mark_Parent_Mode_Object_For_Death()` is called on each arriving unit, so the player does not keep it after the scenario; if `false`, the player may keep the reinforcements.
    * `boolean ignore_reinforcement_rules`: Whether the reinforcements ignore the reinforcement rules and are spawned regardless. Passed to `Reinforce_Unit(...)` inverted, as its last (obey zones) argument. * `[optional] function callback`: A function to call once the `ReinforceList(...)` has finished. It receives the list of arrived units.
    * `boolean callback`

### `function SpawnList(type_list, entry_marker, player, allow_ai_usage, delete_after_scenario)`

Spawns a given list of units simultaneously with `Spawn_Unit(...)` and returns the list of all spawned units.

???+ note "Params"

    * `table type_list`
    * `GameObject|Position|AITargetLocation entry_marker`: The position to spawn the reinforcements at.
    * `Player player`: The player to reinforce.
    * `boolean allow_ai_usage`: Whether the AI may use the spawned units. `Prevent_AI_Usage(...)` is called on every spawned unit either way: with `false` when `allow_ai_usage` is `true`, with `true` otherwise.
    * `boolean delete_after_scenario`: If `true`, `Mark_Parent_Mode_Object_For_Death()` is called on each spawned unit, so the player does not keep it after the scenario; if `false`, the player may keep the units.
