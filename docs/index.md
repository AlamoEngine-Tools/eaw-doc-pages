# Star Wars: Empire at War modding documentation

Community-maintained documentation for Star Wars - Empire at War and its expansion Forces of
Corruption: the tools, the engine's scripting and data formats, and the quirks you only learn by
reading the game.

## Contributing

To contribute, edit or add pages and open a pull request in the
[associated repository](https://github.com/AlamoEngine-Tools/eaw-doc-pages). The Lua reference
and library pages are generated from the language server's stubs; edit those in the
[schema repository](https://github.com/AlamoEngine-Tools/eaw-schema) instead.
